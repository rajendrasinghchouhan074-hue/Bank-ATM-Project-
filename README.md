Bank ATM Management System

About the Project

The Bank ATM Management System is a beginner-friendly Python project that simulates basic ATM operations.

Features

- User PIN authentication
- Check account balance
- Deposit money
- Withdraw money
- Exit the ATM system

Technologies Used

- Python
- Basic programming concepts
- Conditional statements and loops

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the main Python file.

Learning Outcomes

This project helps me practice Python programming, conditional statements, loops, functions, and basic banking operations.
